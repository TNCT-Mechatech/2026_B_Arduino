# 2026_B_Arduino
# ロボット概要
雑巾投げ　わかたけ<br>
各機構-各役割-各アクチュエータ<br>
・射出-雑巾保持-TPPソレノイド(タカハ)<br>
・射出-間欠歯車（棒の先のソレノイドで雑巾を持つ）-DCモータ<br>
・射出-角度変更-サーボモータ（フィーテック社sts3046）<br>
・雑巾送り出しローラ-サーボモータ(フィーテック社sts3215,等速回転モード)<br>
・装填-雑巾持ち上げカム-DCモータ<br>
・補充-アーム開閉-DCモータ<br>
・回収-2段階ラック-DCモータ×２<br>
・回収-ハンド開閉（バケツの中の雑巾をつかむ）-サーボモータ(フィーテック社sts3215)<br>
・オムニ<br>
