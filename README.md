# 2026_B_Arduino
# ロボット概要
雑巾投げ　わかたけ<br>
各機構-各役割-各アクチュエータ
・射出-雑巾保持-TPPソレノイド(タカハ)
・射出-間欠歯車（棒の先のソレノイドで雑巾を持つ）-DCモータ
・射出-角度変更-サーボモータ（フィーテック社sts3046）
・装填-雑巾持ち上げカム-DCモータ
・補充-アーム開閉-DCモータ
・回収-2段階ラック-DCモータ×２
・回収-ハンド開閉（バケツの中の雑巾をつかむ）-サーボモータ(フィーテック社sts3215)
